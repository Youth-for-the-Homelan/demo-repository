          PIAISA - PROPHECY-INSPIRED AUTOMATED ETHICAL SYSTEM ARCHITECTURE
                  مختبر محاكاة النظم والبروتوكولات النبوية الأخلاقية
================================================================================

مرحبًا بك في مشروع PIAISA Core (v1.2.9) - منصة ومختبر ذكاء اصطناعي تفاعلي متكامل 
يهدف إلى نمذجة وترجمة مقاصد السيرة النبوية الشريفة والتقاليد السياسية والاجتماعية 
لعهد الخلفاء الراشدين رضي الله عنهم وتحويلها إلى خوارزميات برمجية تشغيلية وحوكمة 
أخلاقية متعددة الطبقات لحل النزاعات المجتمعية والاقتصادية والسياسية المعاصرة.

This project outlines a 9-layer ethical decision-making design framework that bridges
classical, deep-rooted socio-ethical covenants with modern algorithmic sandbox systems.

--------------------------------------------------------------------------------
1. فلسفة ورؤية المشروع (Project Philosophy & Vision)
--------------------------------------------------------------------------------
يرتكز مختبر المحاكاة الأخلاقي على فكرة تحويل القيم والمواقف والوثائق التاريخية مثل 

(ميثاق المدينة المنورة، حلف الفضول، صلح الحديبية، عام الرمادة، وقف بئر رومة، عهد الصديق) 
إلى "قواعد وقوانين برمجية ذكية" (Algorithmic Covenants). فبدلًا من استخدام نماذج 
الذكاء الاصطناعي كأنظمة عينات عشوائية أو جافة، يلتزم نظام PIAISA بتطبيق فلاتر أخلاقية 
حاكمة وصارمة على طول "خط معالجة القرار السلوكي للأنظمة" في 9 طبقات متميزة ومحكمة.

--------------------------------------------------------------------------------
2. الهيكل الهرمي للطبقات الـ 9 (The 9-Layer Architecture Pipeline)
--------------------------------------------------------------------------------
يتكون النظام من تسع طبقات (من Layer 0 إلى Layer 8)، تتبع تسلسلًا منطقيًا لفحص وحل 
أي مسألة مجتمعية أو نزاع مستخدمين:

• طبقة 0 [L0 :: النواة الأخلاقية والاعتقادية - Core Philosophy]:
  المصدر الموحد للحقيقة (SSOT). تؤصل قيم التوحيد، والعدل، والرحمة، والأمانة قبل أي 
  احتساب مالي أو إجرائي. 
  - السند: حلف الفضول، والعهد الأول لأبي بكر رضي الله عنه: "الضعيف عندي قوي حتى آخذ الحق له".

• طبقة 1 [L1 :: فرز النيات وتقييم المخاطر - Intent Engine & Risk Modeling]:
  التمييز الدلالي للهدف (Greed vs. Desperation) وتحديد أوزان لتخفيف العواقب على المحتاج.
  - السند: قاعدة "الأعمال بالنيات"، وإعمال عمر بن الخطاب في تعطيل حد السرقة عام الرمادة للمضطر.

• طبقة 2 [L2 :: مجلس الشورى التشاركي المتعدد - Shura Governance]:
  منع الانفراد بالقرار عبر محاكاة نقاش حوارتي بين ثلاثة وكلاء أذكياء (مصلح، عادل، أمير).
  - السند: تداول الصحابة رضي الله عنهم في الغزوات والأزمات، وتشكيل عمر للشورى السداسية.

• طبقة 3 [L3 :: بروتوكول شبكة التكافل - Ummah Network & Trust Graph]:
  إعادة توزيع الموارد تلقائيًا لدعم النقاط والأفراد الأضعف في شبكة علاقات ثقة الأمة.
  - السند: بروتوكول المؤاخاة بين المهاجرين والأنصار، وتدوين عمر بن الخطاب للدواوين وكفالة المواليد.

• طبقة 4 [L4 :: محاربة الاستغلال والربا والاحتكار - Anti-Exploitation Economy]:
  تنقية المعاملات الاقتصادية من الاحتكارات والفوائد والربا وضمان عدالة تدفق الموارد.
  - السند: إنشاء السوق الحرة بالمدينة المنورة، وتبرع عثمان بن عفان بوقف بئر رومة العام كسرًا للاحتكار.

• طبقة 5 [L5 :: فض النزاعات والمصالحة - Conflict Mediation]:
  تأسيس واجهات حوارية ومصالحة مرنة قبل المضي في الإجراءات الصارمة أو العقابية.
  - السند: تغليب السلم والحديبية، ومبادئ القضاء والمصالحة في كتاب عمر لأبي موسى الأشعري.

• طبقة 6 [L6 :: السند والمرجع والمعرفة الموثقة - RAG Knowledge Engine]:
  قاعدة معرفية صارمة مدعومة بسلاسل السيرة والأحاديث تمنع الهلوسة الفكرية أو الخوض بغير متيقن.
  - السند: تاريخ الجرح والتعديل وجمع القرآن في عهد الصديق والجمع العثماني المقنن للمصاحف.

• طبقة 7 [L7 :: التنفيذ الفعلي للأفعال والقرارات - Adaptive Action Dispatcher]:
  ترجمة القرارات الأخلاقية إلى نداءات خوارزمية (API) ورسائل إشعار وتنفيذ آمن في الميدان.
  - السند: ديوان البريد ومراسلات النبي إلى ملوك الأرض، وتنظيم المدن الإدارية في عهد الخلفاء.

• طبقة 8 [L8 :: مكبح الأمان والرحمة العظمى - Safety & Mercy Override]:
  موقف الإغاثة الأخير؛ قفل يطيح بالميكانيكية الجافة للقوانين المكتوبة إذا اتضح تسببها في شقاء أو شح للبشر.
  - السند: عهد علي بن أبي طالب لواليه مالك الأشتر: "الناس صنفان: إما أخ لك في الدين أو نظير لك في الخلق".

3. المزايا والقدرات التفاعلية (Interactive Sandbox Features)
--------------------------------------------------------------------------------
يقدم التطبيق بيئة عمل متكاملة تحتوي على المكونات التالية:

1. محاكي النزاع التفاعلي (Simulation Playground):
   - يتيح لك اختيار سيناريوهات جاهزة مصممة وفق عهد النبوة العهد والخلفاء الراشدين.
   - يدعم إيقاد مدخلات وسيناريوهات مخصصة بالكامل (باللغتين العربية والانجليزية مع كاشف تلقائي).
   
2. زمن الخلفاء الراشدين مدمج ومفصل (Righteous Caliphate Integration):
   - تم تفصيل قصص وسجلات عهود أبي بكر، وعمر، وعثمان، وعلي، وتضمينها كمعماريات قابلة للتنفيذ.
   - عند إرسال سيناريوهات متعلقة بـ "المجاعة، عام الرمادة، بئر رومة، درع علي، الابتزاز والظلم"، ينشط محرك المعالجة المتكامل ليظهر القرارات القضائية والوقفية والمالية الشجاعة للخلفاء الراشدين.

3. معايير التحكم في البيئة التكافلية (Environment Sliders & Parameters):
   - مؤشر الثقة العام (General Social Trust Slider): يؤثر على معدلات تقبل الأعضاء في الشبكة.
   - مؤشر الفقر والاحتياج (Vulnerability Pool Scarcity Slider): يدخل تلقائيًا ميزانيات الدعم والزكاة.
   - مؤشر شدة الخلاف (Dispute Severity Slider): يُعيد تنشيط أولويات فك الخصومة والمصالحة السلمية.

4. وحدة التحكم وشريط السجل اللحظي (Live Cybernetic Ethics Terminal):
   - يعرض السجل الفوري لما يحدث خلف الكواليس لتتبع حالة الامتثال والدقة العقدية والأخلاقية.

--------------------------------------------------------------------------------
4. البنية التقنية والفنية للمشروع (Technical Specifications & Setup)
--------------------------------------------------------------------------------
مبني بأحدث تقنيات الويب السلسة لضمان أداء خارق وتصميم مذهل:

- الواجهة الأمامية (Frontend App):
  * React 18+ مع مجمّع Vite فائق السرعة.
  * لغة البرمجة: TypeScript ذات النوعية الصارمة والأمان الكامل (Strict Type-Safety).
  * التنسيق: Tailwind CSS مع تفصيل بؤري للخطوط (Inter & Space Grotesk) والألوان الفولاذية والذهبية الأنيقة.
  * مكتبة الأيقونات الموحدة: Lucide React.
  * محرك تفاعلي لعرض معمارية الطبقات الـ 9 بدوران هندسي أنيق وانتقالات سلسة.

- الواجهة الخلفية (Backend Service):
  * خادم Express ذكي ومحمول متوافق مع الحاويات السحابية وخدمات Cloud Run.
  * معالج هجين (Hybrid Design Engine) مدمج في /server.ts: يوفر محاكاة ذاتية ذكية فورية لجميع فئات السيناريوهات ومطابقتها بالتاريخ الإسلامي والسيرة العثمانية والنبوية والراشدة، مع واجهة للربط التلقائي بنماذج Gemini المعقدة عبر Google GenAI SDK.

--------------------------------------------------------------------------------
5. كيفية التشغيل محليًا (Running & Building the App)
--------------------------------------------------------------------------------
لتشغيل المشروع في بيئة التطوير المحلية وتعديله:

1. تثبيت الاعتماديات (Install Dependencies):
   npm install

2. تشغيل خادم التطوير (Run Development Server):
   npm run dev
   (سيعمل الخادم التلقائي على العنوان: http://localhost:3000)

3. بناء التطبيق للإنتاج (Production Build):
   npm run build
   (سيقوم المترجم ببناء واجهة الابتكار وتجميع خادم Express الفريد في ملف محكم داخل المجلد dist)

4. بدء حزمة الإنتاج (Start Production Server):
   npm run start
